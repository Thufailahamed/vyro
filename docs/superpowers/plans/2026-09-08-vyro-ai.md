# VYRO AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the VYRO AI read-only procurement intelligence MVP described in `docs/superpowers/specs/2026-09-08-vyro-ai-design.md` (commit `f3e2aaa`).

**Architecture:** Deterministic orchestrator over Zod-validated intents. Each intent is a pure async function over existing VYRO repositories (`products`, `supplierProducts`, `suppliers`, `analytics/business`, etc.). A `WorkersAIProvider` is the only AI implementation in MVP; `GeminiProvider` exists as a stub behind the same `AIProvider` interface. Server streams SSE frames (`status`, `tool_call`, `tool_result`, `component`, `final`, `error`) to a React `/ask` page that renders structured components (no `dangerouslySetInnerHTML`).

**Tech Stack:**
- Cloudflare Workers + Hono (existing)
- D1 / KV / Analytics Engine / R2 / Queues (existing)
- Workers AI binding (`@cf/meta/llama-3.1-8b-instruct-fast`, `@cf/meta/llama-3.3-70b-instruct-fp8-fast`)
- Zod (existing) for all AI input/output validation
- React + React Router (existing) for `/ask` page
- vitest (existing) for tests

## Global Constraints

Copied verbatim from spec sections 1-15:

- MVP slice: read-only intelligence only. No write tools in this plan.
- Providers now: Workers AI only. Gemini is a stub.
- Tenants: business buyers only. Supplier/admin AI is out of scope.
- UI surface: backend API + dedicated `/ask` page.
- Response style: server-streamed SSE.
- AI Gateway: not yet. Direct Workers AI calls + Analytics Engine + audit logs.
- Orchestrator: deterministic intent router; LLM only narrates.
- LLM never directly modifies the database (spec section 8). All reads go through existing repository functions in `apps/api/src/modules/*/repository.ts`.
- AI requests restricted to business roles `['owner','manager','staff','purchasing']` (spec section 7).
- Cross-tenant isolation enforced in handler, never in model output (spec section 29).
- Per-tenant token cap 10k tokens/min, configurable via `VYRO_AI_DAILY_TOKEN_CAP` (spec section 8).
- Audit logs: no raw prompt or raw result stored. Only `intent`, `slots`, `toolResults.summaries`, `provider`, `model`, `latencyMs`, `ok`, `errorCode`.
- Provider failure handling: retry once same provider, then SSE `error` event. Per-tool failures emit `tool_result.ok=false` and the orchestrator continues with `narrate` over the remaining successful results.
- Migration: `0018_ai_audit_indexes.sql` adds indexes on `audit_logs(action, created_at)` and a generated `intent` column extracted from `metadata->>'$.intent'`.
- Bindings added: `[[ai]] binding = "AI"` in `wrangler.toml` (default + `[env.production]`).
- Env vars added: `VYRO_AI_ENABLED`, `VYRO_AI_CLASSIFY_MODEL`, `VYRO_AI_NARRATE_MODEL`, `VYRO_AI_DAILY_TOKEN_CAP`.
- Conventional commits. Each task ends with a commit.

## Task Ordering Rationale

Tasks are ordered so each task is independently testable and reviewers can gate between them. Migrations and bindings land first so every later test can run against a real local D1 + Workers AI binding. Pure modules (provider types, stream encoder, intent catalog Zod schemas) land before the orchestrator that composes them. Backend is fully wired before frontend.

```ts
export const INTENT_NAMES = [
  'search_products',
  'find_cheapest',
  'compare_suppliers',
  'supplier_recommend',
  'spend_summary',
  'product_spend',
  'supplier_spend',
  'savings',
  'usual_order',
  'reorder',
  'price_changes',
  'delivery_estimate',
  'clarify',
] as const;

export type IntentName = (typeof INTENT_NAMES)[number];

export const PeriodSchema = z.enum(['week', 'month', 'quarter', 'year']);
export type Period = z.infer<typeof PeriodSchema>;

export const OptimizeForSchema = z.enum(['price', 'speed', 'reliability']);
export type OptimizeFor = z.infer<typeof OptimizeForSchema>;

// Per-intent slot schemas (kept loose; orchestrator normalizes).
const Slots = z.object({
  // search / find / compare / recommend
  query: z.string().min(1).max(120).optional(),
  productName: z.string().min(1).max(120).optional(),
  supplierName: z.string().min(1).max(120).optional(),
  quantity: z.number().int().min(1).max(100000).optional(),
  unit: z.string().min(1).max(20).optional(),
  topN: z.number().int().min(1).max(20).optional(),
  optimizeFor: OptimizeForSchema.optional(),
  // spend / savings / price-changes
  period: PeriodSchema.optional(),
  scope: z.enum(['business', 'category', 'supplier', 'product']).optional(),
  // usual_order
  weeksBack: z.number().int().min(1).max(52).optional(),
  topNProducts: z.number().int().min(1).max(50).optional(),
  // clarify
  question: z.string().max(280).optional(),
  options: z.array(z.string().min(1).max(80)).max(4).optional(),
}).strict();

export type SlotsByIntent = z.infer<typeof Slots>;

export const ClassifyResultSchema = z
  .object({
    intent: z.enum(INTENT_NAMES),
    slots: Slots,
    confidence: z.number().min(0).max(1),
  })
  .strict();

export type ClassifyResult = z.infer<typeof ClassifyResultSchema>;

// Streaming event envelopes (server-emitted, client-consumed).
export const StatusEventSchema = z.object({ stage: z.string() }).strict();
export const ToolCallEventSchema = z
  .object({ name: z.string(), slots: Slots })
  .strict();
export const ToolResultEventSchema = z
  .object({ name: z.string(), ok: z.boolean(), summary: z.string().max(200) })
  .strict();

export const ComponentTypes = [
  'recommendation_card',
  'savings_card',
  'procurement_plan_card',
  'supplier_list_card',
  'spend_summary_card',
  'clarification_card',
] as const;

export const ComponentEnvelopeSchema = z
  .object({
    type: z.enum(ComponentTypes),
    data: z.record(z.unknown()),
  })
  .strict();

export const ActionSchema = z
  .object({
    type: z.enum([
      'view_search',
      'view_supplier',
      'view_product',
      'view_cart',
      'view_orders',
      'view_analytics',
    ]),
    label: z.string().min(1).max(80),
    href: z.string().min(1).max(500),
  })
  .strict();

export const FinalEventSchema = z
  .object({
    summary: z.string().min(1).max(800),
    actions: z.array(ActionSchema).max(6),
  })
  .strict();

export const ErrorEventSchema = z
  .object({ code: z.string().min(1).max(40), message: z.string().min(1).max(200) })
  .strict();

export type ComponentEnvelope = z.infer<typeof ComponentEnvelopeSchema>;
export type FinalEvent = z.infer<typeof FinalEventSchema>;
export type Action = z.infer<typeof ActionSchema>;
```

- [ ] **Step 4: Implement heuristic fallback**

`packages/ai/src/intents.ts`:

```ts
import { INTENT_NAMES, ClassifyResultSchema, type ClassifyResult } from './schemas';

export interface AiDictionary {
  products: string[];
  suppliers: string[];
}

const REORDER_RX = /\b(reorder|restock|due for|what should i (buy|order))\b/i;
const SAVINGS_RX = /\b(save|saving|cheaper|where can i save)\b/i;
const USUAL_RX = /\b(usual|like last time|same as before|my normal)\b/i;
const SPEND_RX = /\b(spend|spent|cost|paid|monthly spend|how much did i)\b/i;
const COMPARE_RX = /\b(compare|vs|versus|which supplier)\b/i;
const DELIVERY_RX = /\b(deliver|delivery|how fast|when can i get)\b/i;
const PRICE_RX = /\b(price increase|price change|why.*increase|why.*more expensive)\b/i;
const SEARCH_RX = /\b(find|search|show me|list)\b/i;
const CHEAPEST_RX = /\b(cheapest|lowest price|best price|best deal)\b/i;

function pickProduct(text: string, products: string[]): string | undefined {
  const lower = text.toLowerCase();
  let best: { name: string; idx: number } | undefined;
  for (const p of products) {
    const idx = lower.indexOf(p.toLowerCase());
    if (idx >= 0 && (!best || idx < best.idx || (idx === best.idx && p.length > best.name.length))) {
      best = { name: p, idx };
    }
  }
  return best?.name;
}

function pickSupplier(text: string, suppliers: string[]): string | undefined {
  const lower = text.toLowerCase();
  return suppliers.find((s) => lower.includes(s.toLowerCase()));
}

function inferQuantity(text: string): { quantity?: number; unit?: string } {
  const m = text.match(/(\d+)\s*(kg|g|l|ml|bottle|bottles|pack|packs|pcs?|pieces?)?/i);
  if (!m) return {};
  const quantity = Number(m[1]);
  const unit = m[2]?.toLowerCase();
  const norm = unit === 'bottles' ? 'bottle' : unit === 'packs' ? 'pack' : unit === 'pcs' || unit === 'pieces' ? 'pc' : unit;
  return { quantity, unit: norm };
}

export function heuristicClassify(text: string, dict: AiDictionary): ClassifyResult {
  const productName = pickProduct(text, dict.products);
  const supplierName = pickSupplier(text, dict.suppliers);
  const qty = inferQuantity(text);

  let intent: ClassifyResult['intent'] = 'clarify';
  let confidence = 0.3;

  if (REORDER_RX.test(text)) {
    intent = 'reorder';
    confidence = 0.7;
  } else if (USUAL_RX.test(text)) {
    intent = 'usual_order';
    confidence = 0.7;
  } else if (SAVINGS_RX.test(text)) {
    intent = 'savings';
    confidence = 0.7;
  } else if (PRICE_RX.test(text)) {
    intent = 'price_changes';
    confidence = 0.7;
  } else if (SPEND_RX.test(text)) {
    intent = 'spend_summary';
    confidence = 0.65;
  } else if (COMPARE_RX.test(text) && productName) {
    intent = 'compare_suppliers';
    confidence = 0.75;
  } else if (CHEAPEST_RX.test(text) && productName) {
    intent = 'find_cheapest';
    confidence = 0.85;
  } else if (DELIVERY_RX.test(text)) {
    intent = 'delivery_estimate';
    confidence = 0.6;
  } else if (SEARCH_RX.test(text) && productName) {
    intent = 'search_products';
    confidence = 0.7;
  }

  const slots: Record<string, unknown> = { ...qty };
  if (productName) slots.productName = productName;
  if (supplierName) slots.supplierName = supplierName;
```

```ts
import type { AIProvider, ChatMessage, ChatOptions, ChatResult } from './types';
import { AIUnavailableError } from './types';
import type { Env } from '../../../env';

const DEFAULT_CLASSIFY = '@cf/meta/llama-3.1-8b-instruct-fast';
const DEFAULT_NARRATE = '@cf/meta/llama-3.3-70b-instruct-fp8-fast';

export class WorkersAIProvider implements AIProvider {
  readonly name = 'workersAI';
  readonly degraded: boolean;
  private readonly env: Env;

  constructor(env: Env) {
    this.env = env;
    this.degraded = !env.AI;
  }

  private resolveModel(opts?: ChatOptions): string {
    if (opts?.model) return opts.model;
    return this.env.VYRO_AI_NARRATE_MODEL || DEFAULT_NARRATE;
  }

  async chat(messages: ChatMessage[], opts?: ChatOptions): Promise<ChatResult> {
    if (this.degraded || !this.env.AI) {
      throw new AIUnavailableError('Workers AI binding not configured');
    }
    const model = this.resolveModel(opts);
    const payload: Record<string, unknown> = { messages };
    if (opts?.temperature !== undefined) payload.temperature = opts.temperature;
    if (opts?.maxTokens !== undefined) payload.max_tokens = opts.maxTokens;
    if (opts?.responseFormatJson) payload.response_format = { type: 'json_object' };

    const started = Date.now();
    let lastErr: unknown;
    for (let attempt = 0; attempt < 2; attempt++) {
      try {
        const res = await this.env.AI!.run(model, payload);
        const latencyMs = Date.now() - started;
        return {
          content: (res as any).response ?? '',
          provider: this.name,
          model,
          latencyMs,
          tokensIn: (res as any).usage?.prompt_tokens,
          tokensOut: (res as any).usage?.completion_tokens,
        };
      } catch (err) {
        lastErr = err;
      }
    }
    throw new AIUnavailableError(
      `Workers AI call failed: ${lastErr instanceof Error ? lastErr.message : 'unknown'}`,
    );
  }
}
```

```ts
import {
  StatusEventSchema,
  ToolCallEventSchema,
  ToolResultEventSchema,
  ComponentEnvelopeSchema,
  FinalEventSchema,
  ErrorEventSchema,
  type ComponentEnvelope,
  type FinalEvent,
} from '@vyro/ai';

export type StreamEvent =
  | { type: 'status'; payload: { stage: string } }
  | { type: 'tool_call'; payload: { name: string; slots: Record<string, unknown> } }
  | { type: 'tool_result'; payload: { name: string; ok: boolean; summary: string } }
  | { type: 'component'; payload: ComponentEnvelope }
  | { type: 'final'; payload: FinalEvent }
  | { type: 'error'; payload: { code: string; message: string } };

const SCHEMAS = {
  status: StatusEventSchema,
  tool_call: ToolCallEventSchema,
  tool_result: ToolResultEventSchema,
  component: ComponentEnvelopeSchema,
  final: FinalEventSchema,
  error: ErrorEventSchema,
} as const;

export function encodeEvent(type: StreamEvent['type'], payload: unknown): string {
  const schema = SCHEMAS[type];
  const parsed = schema.parse(payload);
  return `event: ${type}\ndata: ${JSON.stringify(parsed)}\n\n`;
}

export function validateEvent(type: StreamEvent['type'], data: string): unknown {
  const parsed = JSON.parse(data);
  return SCHEMAS[type].parse(parsed);
}

export function sseHeaders(): Headers {
  const h = new Headers();
  h.set('content-type', 'text/event-stream');
  h.set('cache-control', 'no-cache, no-transform');
  h.set('x-accel-buffering', 'no');
  h.set('connection', 'keep-alive');
  return h;
}
```

```ts
import { ClassifyResultSchema, heuristicClassify, buildClassifyMessages, type ClassifyResult, type AIProvider, type AiDictionary } from '@vyro/ai';

export interface ClassifyContext {
  businessName: string;
  dict: AiDictionary;
}

const PROMPT_MAX = 800;

function safeParse(raw: string): ClassifyResult | null {
  try {
    const obj = JSON.parse(raw);
    return ClassifyResultSchema.parse(obj);
  } catch {
    return null;
  }
}

export async function classify(
  provider: AIProvider,
  ctx: ClassifyContext,
  prompt: string,
): Promise<ClassifyResult> {
  const trimmed = prompt.slice(0, PROMPT_MAX).trim();
  try {
    const messages = buildClassifyMessages(ctx.businessName, trimmed);
    const res = await provider.chat(messages, {
      temperature: 0,
      responseFormatJson: true,
      model: (provider as any).env?.VYRO_AI_CLASSIFY_MODEL,
    });
    const parsed = safeParse(res.content);
    if (parsed) return parsed;
  } catch {
    // fall through
  }
  return heuristicClassify(trimmed, ctx.dict);
}
```

```ts
export interface NarrateContext {
  businessName: string;
}

export interface ToolSummary {
  name: string;
  ok: boolean;
  summary: string;
}

const MAX = 600;

function deterministic(c: NarrateContext, t: ToolSummary): string {
  const prefix = t.ok ? '' : 'Partial result: ';
  return `${prefix}${c.businessName}: ${t.name} ${t.ok ? 'completed' : 'failed'}. ${t.summary}`.slice(0, MAX);
}

export async function narrate(
  provider: AIProvider,
  ctx: NarrateContext,
  tool: ToolSummary,
): Promise<string> {
  try {
    const messages = [
      { role: 'system' as const, content: NARRATE_SYSTEM },
      { role: 'user' as const, content: `Business: ${ctx.businessName}\nTool: ${tool.name}\nResult JSON: ${tool.summary}` },
    ];
    const res = await provider.chat(messages, { temperature: 0.2 });
    return res.content.slice(0, MAX);
  } catch {
    return deterministic(ctx, tool);
  }
}
```

```ts
import { and, eq, isNull, like, sql } from 'drizzle-orm';
import { getDb } from '@vyro/db';
import { products, supplierProducts, suppliers, purchaseOrders } from '@vyro/db/schema';
import type { IntentContext, HandlerResult } from './catalog';

type Score = { supplierId: string; supplierName: string; priceCents: number; leadTimeDays: number; fillRate: number; score: number; rank: number; badge?: 'BEST OVERALL' | 'CHEAPEST' | 'FASTEST' };

export async function supplierRecommendHandler(ctx: IntentContext): Promise<HandlerResult> {
  const db = getDb(ctx.env.DB);
  const name = (ctx.classify.slots.productName ?? '').toLowerCase();
  const focus = ctx.classify.slots.optimizeFor ?? 'reliability';
  if (!name) {
    return { components: [{ type: 'clarification_card', data: { question: 'Which product?', options: [] } }], actions: [], rawSummary: {} };
  }
  const product = await db
    .select()
    .from(products)
    .where(and(isNull(products.deletedAt), like(sql`lower(${products.name})`, `%${name}%`)))
    .limit(1)
    .get();
  if (!product) {
    return { components: [{ type: 'clarification_card', data: { question: `No match for "${name}".`, options: [] } }], actions: [], rawSummary: {} };
  }
  const offers = await db
    .select({ offer: supplierProducts, supplier: suppliers })
    .from(supplierProducts)
    .innerJoin(suppliers, eq(suppliers.id, supplierProducts.supplierId))
    .where(and(eq(supplierProducts.productId, product.id), isNull(supplierProducts.deletedAt), eq(supplierProducts.active, true)))
    .all();
  const live = offers.filter((o) => o.offer.availabilityStatus !== 'out_of_stock');
  if (!live.length) {
    return { components: [{ type: 'recommendation_card', data: { productName: product.name, message: 'No active offers.' } }], actions: [], rawSummary: {} };
  }

  // Fill rate: delivered / total POs with this supplier for this business.
  const supplierIds = [...new Set(live.map((o) => o.supplier.id))];
  const pos = supplierIds.length
    ? await db
        .select()
        .from(purchaseOrders)
        .where(sql`${purchaseOrders.supplierId} in (${sql.join(supplierIds.map((id) => sql`${id}`), sql.raw(','))}) and ${purchaseOrders.businessId} = ${ctx.businessId}`)
        .all()
    : [];

  const stats = new Map<string, { total: number; delivered: number }>();
  for (const p of pos) {
    const s = stats.get(p.supplierId) ?? { total: 0, delivered: 0 };
    s.total++;
    if (p.status === 'delivered') s.delivered++;
    stats.set(p.supplierId, s);
  }

  const minPrice = Math.min(...live.map((o) => o.offer.priceCents));
  const minLead = Math.min(...live.map((o) => o.offer.leadTimeDays));

  const scored: Score[] = live.map((o) => {
    const s = stats.get(o.supplier.id) ?? { total: 0, delivered: 0 };
    const fillRate = s.total === 0 ? 0.5 : s.delivered / s.total;
    const score =
      focus === 'price' ? (1 - o.offer.priceCents / minPrice) :
      focus === 'speed' ? (1 - o.offer.leadTimeDays / Math.max(minLead, 1)) :
      fillRate * 0.6 + (1 - o.offer.priceCents / minPrice) * 0.25 + (1 - o.offer.leadTimeDays / Math.max(minLead, 1)) * 0.15;
    return {
      supplierId: o.supplier.id,
      supplierName: o.supplier.name,
      priceCents: o.offer.priceCents,
      leadTimeDays: o.offer.leadTimeDays,
      fillRate,
      score,
      rank: 0,
    };
  });

  scored.sort((a, b) => b.score - a.score);
  scored.forEach((s, i) => (s.rank = i + 1));

  const cheapest = [...scored].sort((a, b) => a.priceCents - b.priceCents)[0];
  const fastest = [...scored].sort((a, b) => a.leadTimeDays - b.leadTimeDays)[0];
  if (cheapest) cheapest.badge = 'CHEAPEST';
  if (fastest) fastest.badge = 'FASTEST';
  if (scored[0] && scored[0].badge === undefined) scored[0].badge = 'BEST OVERALL';

  return {
    components: [{ type: 'supplier_list_card', data: { title: `Recommended for ${product.name}`, suppliers: scored } }],
    actions: scored.slice(0, 3).map((s) => ({ type: 'view_supplier' as const, label: `View ${s.supplierName}`, href: `/suppliers/${s.supplierId}` })),
    rawSummary: { productId: product.id, focus, winner: scored[0]?.supplierId },
  };
}
```

```ts
export async function reorderHandler(ctx: IntentContext): Promise<HandlerResult> {
  const db = getDb(ctx.env.DB);
  const since = Date.now() - 90 * 24 * 60 * 60 * 1000;
  const rows = await db
    .select({
      productId: purchaseOrderItems.productId,
      productName: products.name,
      lastQty: purchaseOrderItems.quantity,

    .where(and(eq(purchaseOrders.businessId, ctx.businessId), ne(purchaseOrders.status, 'cancelled'), gte(purchaseOrders.createdAt, since)))
    .all();

  const latest = new Map<string, { productId: string; productName: string; lastQty: number; lastCreatedAt: number }>();
  for (const r of rows) {
```

```ts
const PERIOD_DAYS: Record<string, number> = { week: 7, month: 30, quarter: 90, year: 365 };

export async function priceChangesHandler(ctx: IntentContext): Promise<HandlerResult> {
  const period = ctx.classify.slots.period ?? 'month';
  const since = Date.now() - (PERIOD_DAYS[period] ?? 30) * 24 * 60 * 60 * 1000;
  const db = getDb(ctx.env.DB);
  const rows = await db
    .select({
      productId: purchaseOrderItems.productId,
      productName: products.name,
      unitPriceCents: purchaseOrderItems.unitPriceCents,
      createdAt: purchaseOrders.createdAt,
    })

    .innerJoin(purchaseOrders, eq(purchaseOrders.id, purchaseOrderItems.purchaseOrderId))
    .innerJoin(products, eq(products.id, purchaseOrderItems.productId))
    .where(and(eq(purchaseOrders.businessId, ctx.businessId), ne(purchaseOrders.status, 'cancelled'), gte(purchaseOrders.createdAt, since)))
    .all();

  const byProd = new Map<string, Array<{ price: number; ts: number }>>();
  for (const r of rows) {
    const arr = byProd.get(r.productId) ?? [];
    arr.push({ price: r.unitPriceCents, ts: r.createdAt });
    byProd.set(r.productId, arr);
  }
  const movers: Array<{ productName: string; from: number; to: number; pct: number }> = [];
  for (const [, arr] of byProd) {
    arr.sort((a, b) => a.ts - b.ts);
    if (arr.length < 2) continue;
    const from = arr[0].price;
    const to = arr[arr.length - 1].price;
    if (from === 0) continue;
    const pct = Math.round(((to - from) / from) * 100);
    movers.push({ productName: arr[0].price ? '' : '', from, to, pct } as any);
  }
  // Enrich names
  for (const m of movers) {
    const sample = rows.find((r) => r.unitPriceCents === m.from || r.unitPriceCents === m.to);
    m.productName = sample?.productName ?? '—';
  }
  movers.sort((a, b) => Math.abs(b.pct) - Math.abs(a.pct));

  return {
    components: [{
      type: 'spend_summary_card',
      data: { scope: 'price_changes', period, movers },
    }],
    actions: [{ type: 'view_analytics', label: 'Open analytics', href: '/analytics' }],
```

```ts
import { and, eq, isNull, like, sql } from 'drizzle-orm';
import { getDb } from '@vyro/db';
import { products, supplierProducts, suppliers } from '@vyro/db/schema';
import type { IntentContext, HandlerResult } from './catalog';

export async function deliveryEstimateHandler(ctx: IntentContext): Promise<HandlerResult> {
  const db = getDb(ctx.env.DB);
  const name = (ctx.classify.slots.productName ?? '').toLowerCase();
  const supplier = (ctx.classify.slots.supplierName ?? '').toLowerCase();

  if (!name && !supplier) {
    return { components: [{ type: 'clarification_card', data: { question: 'Which product or supplier?', options: [] } }], actions: [], rawSummary: {} };
  }

  const conds = [isNull(supplierProducts.deletedAt), eq(supplierProducts.active, true)] as any[];
  if (name) {
    const p = await db
      .select()
      .from(products)
      .where(and(isNull(products.deletedAt), like(sql`lower(${products.name})`, `%${name}%`)))
      .limit(1)
      .get();
    if (!p) return { components: [{ type: 'clarification_card', data: { question: `No match for "${name}".`, options: [] } }], actions: [], rawSummary: {} };
    conds.push(eq(supplierProducts.productId, p.id));
  }
  if (supplier) conds.push(like(sql`lower(${suppliers.name})`, `%${supplier}%`));

  const rows = await db
    .select({ supplierName: suppliers.name, supplierId: suppliers.id, leadTimeDays: supplierProducts.leadTimeDays, deliveryAvailable: supplierProducts.deliveryAvailable, deliveryRadiusKm: supplierProducts.deliveryRadiusKm })
    .from(supplierProducts)
    .innerJoin(suppliers, eq(suppliers.id, supplierProducts.supplierId))
    .where(and(...conds))
    .all();

  const list = rows.sort((a, b) => a.leadTimeDays - b.leadTimeDays).map((r) => ({
    supplierName: r.supplierName,
    supplierId: r.supplierId,
    leadTimeDays: r.leadTimeDays,
    deliveryAvailable: !!r.deliveryAvailable,
    deliveryRadiusKm: r.deliveryRadiusKm,
  }));

  return {
    components: [{ type: 'supplier_list_card', data: { title: 'Delivery estimates', suppliers: list } }],
    actions: list.slice(0, 3).map((s) => ({ type: 'view_supplier' as const, label: `View ${s.supplierName}`, href: `/suppliers/${s.supplierId}` })),
    rawSummary: { count: list.length },
  };
```

```ts
import type { Env } from '../../env';
import { httpError } from '../../lib/errors';

const WINDOW_MS = 60 * 1000;
const TOKEN_BUDGET_PER_MIN = 10_000;
const windows = new Map<string, { tokens: number; resetAt: number }>();

export function assertAiEnabled(env: Env): void {
  if (env.VYRO_AI_ENABLED !== 'true') {
    throw httpError(503, 'AI_DISABLED', 'VYRO AI is currently disabled');
  }
}

export function costCap(env: Env, businessId: string, tokensRequest: number): { ok: boolean; retryAfterSec: number } {
  const cap = Number(env.VYRO_AI_DAILY_TOKEN_CAP ?? '200000') / (24 * 60); // per minute approx
  const limit = Math.min(TOKEN_BUDGET_PER_MIN, Math.max(1, Math.floor(cap)));
  const now = Date.now();
  const w = windows.get(businessId);
  if (!w || w.resetAt < now) {
    windows.set(businessId, { tokens: tokensRequest, resetAt: now + WINDOW_MS });
    return { ok: true, retryAfterSec: 0 };
  }
  if (w.tokens + tokensRequest > limit) {
    return { ok: false, retryAfterSec: Math.ceil((w.resetAt - now) / 1000) };
  }
  w.tokens += tokensRequest;
  return { ok: true, retryAfterSec: 0 };
}

export const PROMPT_MAX = 800;

export function assertPromptSafe(prompt: unknown): string {
  if (typeof prompt !== 'string') throw httpError(400, 'VALIDATION_ERROR', 'prompt required');
  if (prompt.length > PROMPT_MAX) throw httpError(400, 'PROMPT_TOO_LONG', `prompt exceeds ${PROMPT_MAX} chars`);
  if (/[\w.+-]+@[\w-]+\.[\w.-]+/.test(prompt)) throw httpError(400, 'INVALID_PROMPT', 'prompt contains what looks like an email');
  return prompt.slice(0, PROMPT_MAX).trim();
}
```

```ts
import { AIProvider, ChatMessage } from '@vyro/ai';
import { providerFor } from './provider';
import { classify, type ClassifyContext } from './classify';
import { narrate } from './narrate';
import { HANDLERS, type IntentContext } from './intents/catalog';
import { encodeEvent } from './stream';
import { writeAiAudit } from './audit';
import { recordAiMetric } from './metrics';
import { assertPromptSafe, costCap } from './guard';
import type { Env } from '../../env';
import { newId } from '@vyro/shared';

export interface OrchestrateContext extends ClassifyContext {
  userId: string;
  businessId: string;
  conversation?: ChatMessage[];
}

export async function* orchestrate(env: Env, ctx: OrchestrateContext, rawPrompt: string): AsyncGenerator<string> {
  const requestId = newId();
  const started = Date.now();
  let ok = true;
  let errorCode: string | undefined;
  let intentName = 'clarify';
  let providerName = 'workersAI';
  let modelName = env.VYRO_AI_NARRATE_MODEL ?? 'unknown';
  let tokensIn: number | undefined;
  let tokensOut: number | undefined;

  const prompt = assertPromptSafe(rawPrompt);
  const cap = costCap(env, ctx.businessId, 200); // estimate per request
  if (!cap.ok) {
    yield encodeEvent('error', { code: 'RATE_LIMITED', message: `AI is busy. Retry in ${cap.retryAfterSec}s` });
    return;
  }

  yield encodeEvent('status', { stage: 'classifying' });

  const provider = providerFor(env);
  providerName = provider.name;

  try {
    const classifyResult = await classify(provider, ctx, prompt);
    intentName = classifyResult.intent;
    yield encodeEvent('tool_call', { name: classifyResult.intent, slots: classifyResult.slots });

    const handlerCtx: IntentContext = {
      env,
      businessId: ctx.businessId,
      userId: ctx.userId,
      classify: classifyResult,
    };
    let handlerResult;
    try {
      handlerResult = await HANDLERS[classifyResult.intent](handlerCtx);
    } catch (err) {
      ok = false;
      errorCode = 'HANDLER_FAILED';
      yield encodeEvent('tool_result', { name: classifyResult.intent, ok: false, summary: err instanceof Error ? err.message : 'handler failed' });
      handlerResult = { components: [], actions: [], rawSummary: {} };
    }
    yield encodeEvent('tool_result', { name: classifyResult.intent, ok: true, summary: JSON.stringify(handlerResult.rawSummary).slice(0, 200) });
    for (const c of handlerResult.components) yield encodeEvent('component', c);

    const narration = await narrate(provider, { businessName: ctx.businessName }, {
      name: classifyResult.intent, ok: true, summary: JSON.stringify(handlerResult.rawSummary),
    });

    yield encodeEvent('final', { summary: narration, actions: handlerResult.actions });
  } catch (err) {
    ok = false;
    errorCode = 'AI_UNAVAILABLE';
    yield encodeEvent('error', { code: errorCode, message: err instanceof Error ? err.message : 'AI unavailable' });
  }

  const latencyMs = Date.now() - started;
  await writeAiAudit(env, {
    userId: ctx.userId, businessId: ctx.businessId, intent: intentName,
    provider: providerName, model: modelName, latencyMs,
    tokensIn, tokensOut, ok, errorCode, requestId, slots: ctx.classify?.slots,
  }).catch(() => undefined);
  recordAiMetric(env, {
    businessId: ctx.businessId, userId: ctx.userId, intent: intentName,
    provider: providerName, model: modelName, latencyMs,
    tokensIn, tokensOut, ok, errorCode,
  });
}
```

```ts
import { useReducer, useCallback } from 'react';
import type { ComponentEnvelope } from '@vyro/ai';
import { ComponentEnvelopeSchema, FinalEventSchema, ErrorEventSchema, ToolCallEventSchema, StatusEventSchema } from '@vyro/ai';

export interface VyroAIState {
  loading: boolean;
  components: ComponentEnvelope[];
  summary?: string;
  actions: Array<{ type: string; label: string; href: string }>;
  error?: { code: string; message: string };
  toolCall?: { name: string; slots: Record<string, unknown> };
  status?: string;
}

const initial: VyroAIState = { loading: false, components: [], actions: [] };

type Action =
  | { type: 'reset' }
  | { type: 'loading'; loading: boolean }
  | { type: 'status'; stage: string }
  | { type: 'tool_call'; name: string; slots: Record<string, unknown> }
  | { type: 'component'; c: ComponentEnvelope }
  | { type: 'final'; summary: string; actions: VyroAIState['actions'] }
  | { type: 'error'; code: string; message: string };

function reducer(s: VyroAIState, a: Action): VyroAIState {
  switch (a.type) {
    case 'reset': return { ...initial };
    case 'loading': return { ...s, loading: a.loading };
    case 'status': return { ...s, status: a.stage };
    case 'tool_call': return { ...s, toolCall: { name: a.name, slots: a.slots } };
    case 'component': return { ...s, components: [...s.components, a.c] };
    case 'final': return { ...s, summary: a.summary, actions: a.actions, loading: false };
    case 'error': return { ...s, error: { code: a.code, message: a.message }, loading: false };
  }
}

async function* parseSSE(res: Response): AsyncGenerator<[string, string]> {
  const reader = res.body!.getReader();
  const dec = new TextDecoder();
  let buf = '';
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buf += dec.decode(value, { stream: true });
    let idx;
    while ((idx = buf.indexOf('\n\n')) !== -1) {
      const frame = buf.slice(0, idx);
      buf = buf.slice(idx + 2);
      const lines = frame.split('\n');
      let type = '';
      let data = '';
      for (const line of lines) {
        if (line.startsWith('event: ')) type = line.slice(7).trim();
        else if (line.startsWith('data: ')) data += line.slice(6);
      }
      if (type && data) yield [type, data];
    }
  }
}

export function useVyroAI() {
  const [state, dispatch] = useReducer(reducer, initial);
  const send = useCallback(async (prompt: string, opts?: { businessId?: string }) => {
    dispatch({ type: 'reset' });
    dispatch({ type: 'loading', loading: true });
    const res = await fetch('/api/ai/ask', {
      method: 'POST',
      credentials: 'include',
      headers: { 'content-type': 'application/json', 'accept': 'text/event-stream' },
      body: JSON.stringify({ prompt, businessId: opts?.businessId }),
    });
    if (!res.ok || !res.body) {
      dispatch({ type: 'error', code: 'HTTP_ERROR', message: `HTTP ${res.status}` });
      return;
    }
    for await (const [type, data] of parseSSE(res)) {
      try {
        switch (type) {
          case 'status': {
            const v = StatusEventSchema.parse(JSON.parse(data));
            dispatch({ type: 'status', stage: v.stage });
            break;
          }
          case 'tool_call': {
            const v = ToolCallEventSchema.parse(JSON.parse(data));
            dispatch({ type: 'tool_call', name: v.name, slots: v.slots });
            break;
          }
          case 'tool_result':
            // informational; no UI mutation needed for MVP
            break;
          case 'component': {
            const v = ComponentEnvelopeSchema.parse(JSON.parse(data));
            dispatch({ type: 'component', c: v });
            break;
          }
          case 'final': {
            const v = FinalEventSchema.parse(JSON.parse(data));
            dispatch({ type: 'final', summary: v.summary, actions: v.actions as any });
            break;
          }
          case 'error': {
            const v = ErrorEventSchema.parse(JSON.parse(data));
            dispatch({ type: 'error', code: v.code, message: v.message });
            break;
          }
        }
      } catch (err) {
        dispatch({ type: 'error', code: 'PARSE_ERROR', message: err instanceof Error ? err.message : 'parse' });
      }
    }
    dispatch({ type: 'loading', loading: false });
  }, []);
  return { state, send };
}
```
